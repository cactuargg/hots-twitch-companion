# Запуск Twitch Predictions без симуляции — v0.9.1

Мастер: выбрать игрока → подключить Twitch → «Запустить Twitch Predictions».
Twitch обязателен для перехода к запуску; на последнем шаге показано, что
используются настоящие баллы зрителей. Можно закончить настройку без запуска.
На главной и в мастере один общий запуск с подтверждением реальных Predictions.
Сохранение настроек, подключение Twitch, перезапуск и закрытие мастера сами
по себе мониторинг не запускают.

В настройках больше нет переключателя симуляции. Профиль и API config всегда
используют реальные Predictions. API запуска требует confirmedRealMode=true
и подключённый Twitch; старые запросы запуска без подтверждения отклоняются.
Проверка токена/прав в движке выполняется перед обработкой матчей.

При загрузке старого профиля realMode=false заменяется на true без запуска
мониторинга. Только локальный Active с dryRun=true и его очередь удаляются.
Реальный Prediction, привязка матча, выбранный исход и история использованных
лобби сохраняются. Никаких отмен/выплат при миграции нет.

Dry-run в Go оставлен только для изолированных тестов движка, не как режим
приложения. Тесты не создают реальные Predictions и не распределяют баллы.
Подтверждения ручного Win/Loss/Cancel, строгая корреляция матча и блокировка
автовыплат при неоднозначности сохранены.

При расчёте результата (автоматическом или ручном Win/Loss) приложение читает
суммы Channel Points обоих исходов из Twitch. Если хотя бы на одном исходе
0 баллов, прогноз отменяется с возвратом баллов всем участникам независимо
от победителя матча. Проверка выполняется при расчёте, а не при закрытии приёма
ставок. При ненулевых суммах на обоих исходах выполняется обычный расчёт.
Если суммы не получены или некорректны, расчёт откладывается до повторной
проверки. Решение о возврате сохраняется до запроса отмены и переживает
сетевые ошибки и перезапуск. Уже завершённый на Twitch прогноз не меняется.

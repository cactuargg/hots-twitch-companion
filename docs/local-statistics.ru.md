# Локальная статистика реплеев

На главном экране раскрой «Локальная статистика реплеев».
В таблицах есть винрейт героев, винрейт игроков и разбор игрока по героям:
выбери «Игроки» и нажми на имя. Фильтр режима независим от фильтра истории
сессии. Доступны поиск, число игр, победы, поражения и страницы по 25 строк.
Строки упорядочены по числу наблюдений, а не по максимальному проценту.

## Наполнение базы

Нажми «Импортировать реплеи», чтобы обработать старые файлы из настроенной
папки текущего профиля (или стандартных папок HotS, если путь пустой).
Учитываются все найденные участники, даже если выбранного игрока в матче нет.
Существующий импорт истории также наполняет эту базу. Чтобы добавить другую
папку аккаунта, выбери соответствующий игровой профиль и запусти импорт.

Новые стабильные реплеи собираются в фоне, пока Companion работает и в нём
выбран игрок. Включать мониторинг Twitch, счётчик или маску не требуется.
Фоновый поиск использует настроенную папку и прежнюю границу сканирования
истории; для более старых файлов нужен явный импорт. Запись ещё изменяющегося
реплея откладывается до стабилизации файла.

## Что означают цифры

- Это наблюдаемый винрейт только в доступных локальных реплеях. Он не является
  глобальным винрейтом, рейтингом Blizzard или прогнозом следующего матча.
- Игрок определяется по Toon Handle, не по нику. Смена ника сохраняет
  статистику; одинаковые ники с разными ID считаются разными людьми.
- Учитываются победы и поражения людей с корректным ID. ИИ, неизвестные
  результаты и повторяющиеся ID внутри одного матча пропускаются.
- Для героя считаются результаты участников на этом герое. Если в матче
  два одинаковых героя, это две игры за героя, а не один результат команды.
- Пустой герой не создаёт строку героя, но известный результат человека
  может войти в его личную статистику.
- Пометка «Малая выборка» означает меньше 20 наблюдений; это подсказка о
  размере выборки, не вычисленный уровень статистической достоверности.
- Режимы можно разделять. «Не определён / своя игра» включает файлы, для
  которых текущий парсер не установил обычный режим. Неизвестный режим не
  приписывается Storm League. Для сравнения игроков выбирай одинаковый режим.

## Хранение и нагрузка

База replay-statistics.json хранится в локальном профиле Companion и общая
для всех игровых профилей. Интернет-запросы и внешние сервисы не используются.
Копии с идентичным содержимым определяются по SHA-256 и учитываются один раз,
даже из разных папок. Разные файлы одного матча, записанные разными клиентами,
не гарантированно объединяются — общего подтверждённого ID матча пока нет.

При повторном импорте уже известное содержимое не декодируется заново.
Фоновая обработка ограничена четырьмя файлами за проход, записи группируются;
агрегаты кэшируются до появления новых реплеев. Закрытая панель не запрашивает
таблицы; открытая обновляется раз в 15 секунд. База первого варианта хранится
в JSON, поэтому очень большие архивы требуют отдельной проверки нагрузки.

Счёт сессии, его ручные исправления, исключения и удаление игровых профилей
не меняют исходные результаты в этой отдельной базе. Исторический импорт
не прибавляет победы и поражения к текущему счётчику сессии.
Полный сброс профиля удаляет и локальную статистику; исходные реплеи остаются.
Если база повреждена, приложение показывает ошибку и не перезаписывает её.

Это основа для дальнейшей модели вероятности победы. Такая модель в этом
изменении не добавляется.

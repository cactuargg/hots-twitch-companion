# Compact Desktop — подготовка v0.9.1

Основная сборка Windows теперь использует Wails v2/WebView2: окно 520×740,
минимум 480×540, максимальная ширина 560 логических пикселей. Windows масштабирует
их по DPI. Высоту можно менять; длинные настройки, история и мастер прокручиваются.
Основные три раздела, диагностика, ручные исходы и подтверждения выплат сохранены.
Компактные стили включаются только в нативном окне; браузерная сборка сохраняет
прежнюю адаптивную компоновку.

Собственный заголовок позволяет перетаскивать окно. Кнопки справа:

- «Свернуть» — обычное сворачивание в панель задач.
- «В трей» — скрывает окно, мониторинг продолжает работать. Если трей ещё не
  инициализирован, окно остаётся открытым и показывает ошибку.
- «Закрыть» — завершает приложение. При мониторинге или активном Prediction
  запрашивается прежнее подтверждение с отказом по умолчанию. Prediction
  сохраняется; закрытие само по себе не делает запрос отмены/выплаты в Twitch.

Клик по значку H в трее и пункт «Открыть» восстанавливают окно. Пункт «Выход»
показывает окно и вызывает то же подтверждение закрытия. Меню намеренно не
содержит управления Prediction. Трей реализован закреплённой fyne.io/systray
v1.12.2 с отдельным потоком сообщений Windows; при выходе значок удаляется.
Названия пунктов берутся из языка профиля при запуске.

Встроенная иконка EXE и значок трея повторяют текущий H-знак интерфейса.
SVG и Go-генератор находятся в assets/ и cmd/companion/web/assets/app-icon.svg.
Перегенерация: `./assets/generate.ps1` (go-winres v0.3.3, RT_GROUP_ICON #3 для Wails).
Сгенерированный rsrc_windows_amd64.syso хранится в Git; обычная сборка не требует
генератора. Ресурс включает версию, запуск без повышения прав и PerMonitorV2 DPI.

## Сборка

```powershell
./build.ps1                  # основной Desktop EXE и ZIP
./build.ps1 -BrowserFallback # отдельный Browser EXE и ZIP
./dist/HotS-Twitch-Companion-v0.9.1.exe --data-dir ./.research/compact-profile
```

Требуются Go 1.25+ и Node.js 18+. В рабочем приложении нужны Windows x64 и
WebView2 Evergreen Runtime; Go/Node.js не нужны. Runtime автоматически не
скачивается. [Установка Microsoft WebView2](https://developer.microsoft.com/microsoft-edge/webview2/).
Если он недоступен, можно собрать BrowserFallback или воспользоваться его
отдельным CI-артефактом. Не запускайте два EXE с одним профилем; перед новой
версией закройте старый v0.8.0, не учитывающий блокировку профиля.

`build-desktop.ps1` оставлен как совместимый вызов основного build.ps1.
CI проверяет обе конфигурации и публикует отдельные артефакты. Обычный тег v0.9.1
публикует Desktop EXE и ZIP; сам PR не создаёт тег или релиз.

Проверки перед выпуском: подключение Twitch и подтверждение запуска, главная/история/настройки/мастер,
изменение размера и DPI, сворачивание, скрытие/восстановление через трей,
отказ и подтверждение выхода. Реальные выплаты не входят в UI smoke-test.

Локальная проверка реализации: Go test/vet обеих конфигураций, 54 JS-теста,
синтаксис JS, Windows EXE/ZIP и метаданные 0.9.1. В видимом WebView2 проверены
главная, история и настройки при 520×740, скрытие окна без завершения процесса.
Полная ручная матрица трея (восстановление и выход из меню) и 125–150% DPI
должна быть проверена на целевой Windows перед выпуском; автоматизация Windows
в этой среде не предоставляет поверхность панели уведомлений.

Исследование: [Wails Frameless](https://v2.wails.io/docs/guides/frameless/),
[API systray](https://pkg.go.dev/fyne.io/systray@v1.12.2).

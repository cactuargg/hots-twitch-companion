# OBS-виджет статистики лобби

## Настройка

1. Открой «Настройки → Оверлеи OBS → Виджет статистики лобби».
2. Включи «Показывать виджет лобби в OBS» и нажми «Сохранить изменения».
3. Нажми «Скопировать URL для OBS» именно в этой карточке.
4. В OBS добавь источник «Браузер», вставь URL, задай ширину 560 и высоту 820.
   Фон вне плашки прозрачный. URL отличается от источников счёта и маски.
5. Оставь Companion работающим. При отсутствии текущего лобби виджет
   показывает ожидание, при отключённом переключателе скрывается.

В той же карточке есть живой предпросмотр. Он обращается к сохранённым
настройкам, поэтому после изменения переключателя сначала сохрани настройки.
При закрытии предпросмотра его опрос прекращается.

## Данные

Вверху отображаются игрок, герой из текущего BattleLobby, локальный винрейт
этого игрока на герое и число наблюдаемых игр. Используется статистика только
текущего игрового режима; данные ARAM и Storm League не складываются.

Ниже — другие участники этого лобби, у которых уже есть локальные наблюдения:
имя из истории, общий винрейт и число игр в этом режиме, статистика текущего
героя (когда он определён), число общих матчей со стримером. Общие матчи
означают присутствие в одном реплее — не обязательно игру в одной команде.
В этом выпуске стороны текущего лобби не угадываются по порядку игроков.

Имена берутся из локальной истории и могут отставать от недавнего переименования.
Внутренние ID, пути файлов, токены и полный архив в данные OBS не передаются.
Неизвестные участники не получают выдуманного винрейта. При нуле игр вместо
процента показывается «—», менее 20 игр помечаются как малая выборка.
Это наблюдаемые результаты из реплеев, не вероятность победы текущего матча.

## Откуда берётся текущий герой

Свежий BattleLobby читается при загрузке/начале матча; обновление может занять
несколько секунд. Нужен Toon Handle выбранного игрового профиля и поддержанный
формат лобби. Если профиль отсутствует в лобби, данные старого матча не показываются.

В ARAM герой в BattleLobby может быть препиком, а не полученным случайным героем.
Поэтому виджет честно показывает «Герой не подтверждён» и общий винрейт игрока
по этому режиму. При неизвестном коде героя также используется общая статистика.
После окончания матча в базу попадёт фактический герой из завершённого реплея.

Источником названий служит встроенный MIT-справочник HeroesToolChest/heroes-data,
build 93640, на русском и английском; сопоставление учитывает имена из реплеев.
Сетевые запросы для имён и статистики во время матча не выполняются.

## Обновление и нагрузка

OBS запрашивает компактное состояние раз в 1,5 секунды; запросы не накладываются.
Готовые показатели кэшируются до смены лобби, игрока, языка или пополнения базы.
История целиком не копируется для опроса виджета, реплеи повторно не разбираются.
Если лобби устарело, изменилось, исчезло, завершено или профиль сменился,
плашка убирает прежнего героя и участников. При потере связи она показывает
сообщение об отключении вместо старых процентов.

Для наполнения базы используй «Обзор → Локальная статистика реплеев →
Импортировать реплеи». Новые стабильные реплеи продолжают сохраняться автоматически.
Ни счётчик сессии, ни мониторинг Twitch для работы виджета не обязательны.

# Desktop Shell — пилот Wails/WebView2

PR #21 добавляет отдельный Windows EXE с прежними Go-логикой и HTML/CSS/JS.
Браузерная сборка остаётся основной. Версия приложения пока 0.8.0;
компактный интерфейс, собственный заголовок, иконка и трей относятся к PR #22.

## Выбор технологии

Выбран стабильный Wails v2.15.0. Wails v3 пока beta. Прямой go-webview2
предоставляет COM-обёртки и потребовал бы собственной реализации окна Win32,
цикла сообщений, диалогов и завершения процесса. Wails уже решает эти задачи.
Переписывать Go-движок и интерфейс не требуется.

- [Параметры Wails](https://v2.wails.io/docs/reference/options/)
- [Windows / WebView2](https://v2.wails.io/docs/guides/windows/)
- [Архитектура](https://v2.wails.io/docs/howdoesitwork/)

AssetServer.Handler направляет запросы WebView2 в существующий dashboard.routes.
TCP-порт не открывается; привязок Go-методов к JavaScript нет. Адаптер меняет
только путь: Host, Origin, X-Companion и Sec-Fetch-Site проверяются прежними
обработчиками. CSP сохраняется. Twitch-ссылки открываются системным браузером
через runtime Wails; разрешён только HTTPS на известных доменах Twitch.

Крестик окна при работающем мониторинге или активном Prediction запрашивает
подтверждение, по умолчанию выбран отказ. Закрытие останавливает мониторинг,
сохранённый Prediction остаётся для восстановления при следующем запуске.
Закрытие само по себе не отменяет Prediction и не распределяет баллы.
Кнопка «Выход» использует прежнее подтверждение без второго диалога.

Новые браузерная и Desktop сборки эксклюзивно блокируют каталог профиля.
Windows освобождает блокировку при аварии. Старые EXE v0.8.0 этой блокировки
не знают: перед пилотом нужно закрыть старый экземпляр. DPAPI и форматы
config/state сохраняются; данные WebView2 находятся в подпапке webview2.

## Сборка и проверка

Требуются Windows x64, Go 1.25+ (минимум Wails v2.15.0), Node.js 18+.
Пользователю Go и Node.js не нужны. Нужен установленный Microsoft Edge
WebView2 Evergreen Runtime. При его отсутствии EXE показывает ошибку;
автоматического скачивания и установки нет.
[Официальная установка Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

```powershell
./build-desktop.ps1
./dist/desktop-pilot/HotS-Twitch-Companion-Desktop.exe --data-dir ./.research/my-pilot-profile
```

Скрипт запускает Go-тесты обеих сборок, vet пилота, JS syntax и JS-тесты,
затем собирает отдельный ZIP с лицензиями и SHA256. Используются теги
`wails,production,wv2runtime.error`; Wails CLI и frontend toolchain не нужны.
CI загружает отдельный артефакт Desktop Pilot, не добавляя его в стабильный релиз.
Без --data-dir используется прежний пользовательский профиль.

Проверять без Twitch-токенов и в симуляции: главная/история/настройки,
сохранение настроек, старт/стоп мониторинга, отказ и подтверждение закрытия,
кнопку «Выход», повторный запуск и блокировку второго экземпляра.
Сценарии настоящей авторизации и реальных выплат требуют отдельной проверки
владельцем канала; при разработке реальные Predictions не создаются.

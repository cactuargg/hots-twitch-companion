# Игровые профили HotS

Профиль хранит название, ник, внутренний ID игрока (Toon Handle) и папку
реплеев. Вход в Battle.net не выполняется, пароли не запрашиваются.
Twitch, параметры прогнозов, настройки оверлеев, CSS-темы и ссылки OBS общие.

## Обновление без сброса

При обновлении текущий игрок автоматически становится первым профилем.
Ник, ID и папка реплеев сохраняются. При следующем сохранении настроек
библиотека профилей записывается в config.json. Подключение Twitch,
история сессий и ссылки OBS не меняются.

## Добавление второго аккаунта

1. Заверши текущий прогноз и останови мониторинг.
2. Сыграй матч на новом аккаунте, чтобы появился реплей.
3. Открой «Настройки → Heroes of the Storm → Игровые профили» и нажми
   «Добавить аккаунт». Введи понятное название.
4. Нажми «Выбрать игрока из реплея» и выбери себя. Ник и Toon Handle
   заполнятся автоматически. Для автоматики нужен Toon Handle, не только ник.
5. Если используется отдельная папка реплеев, укажи её в расширенных
   настройках. Пустой путь включает стандартный поиск по папкам HotS.
6. Нажми «Сохранить изменения». Выбранный профиль станет активным.

Если реплея нового аккаунта ещё нет, можно заранее добавить профиль,
вернуться к прежнему в списке «Редактируемый профиль» и сохранить настройки.
Пустой профиль хранится в списке, но для работы его нужно заполнить.
Выбор нового профиля не переключает аккаунт в игре: войди в нужный Battle.net
самостоятельно. Приложение отслеживает выбранного игрока.

## Переключение

На главном экране выбери «Активный аккаунт». Переключение сразу сохраняется.
В настройках выбор профиля и правки применяются общей кнопкой
«Сохранить изменения». Перед быстрым переключением сохрани черновики,
включая оформление OBS. Мониторинг после переключения запусти самостоятельно.

Смена профиля, игрока или папки запрещена при работающем мониторинге,
незавершённом прогнозе или неподтверждённом создании прогноза на Twitch.
Ожидающие лобби прежнего игрока при смене сбрасываются; уже обработанные
матчи и их история не удаляются.

## История и удаление

Статистика и текущая сессия привязаны к внутреннему ID игрока. Возвращение
к старому аккаунту возвращает его историю и сессию. Два названия профиля
с одним ID игрока используют ту же статистику. Общего счёта между разными
аккаунтами в этой версии нет.

Название можно изменить в настройках. «Удалить профиль» удаляет только
запись из списка после сохранения; матчи и сессии остаются. Нельзя удалить
последний профиль через интерфейс. Поддерживается до восьми профилей.
Полный сброс приложения удаляет и список профилей, поэтому для смены
аккаунта он не нужен.

# Версия пакета и сброс данных

Имена собираемых EXE и ZIP содержат версию из `cmd/companion/version.go`: например,
`HotS-Twitch-Companion-v0.9.1.exe` и
`HotS-Twitch-Companion-v0.9.1-windows-x64.zip`.
Браузерный вариант содержит также `Browser`. Локальная сборка и CI используют
один build.ps1; контрольные суммы и release notes ссылаются на эти же имена.
Релизный тег должен совпадать с appVersion.

Версия видна внизу интерфейса. В Desktop нижняя кнопка «Выход» скрыта:
закрытие доступно в заголовке и трее. В BrowserFallback кнопка остаётся,
поскольку закрытие вкладки не завершает локальный процесс сразу.

Для проверки первоначальной настройки открой «Настройки → Пользовательские
данные → Очистить пользовательские данные». Подтверди сброс и запусти EXE снова.
Приложение закроется; при следующем запуске, под блокировкой профиля и до
загрузки настроек/токенов/WebView2, удалятся только файлы Companion:
config.json, state.json, tokens.dpapi, их временные .new и каталог webview2.
Реплеи HotS не удаляются. Вход Twitch в системном браузере и доступ приложения
на стороне Twitch не отзываются; локальное подключение Companion будет очищено.
Настройка начнётся заново; мониторинг сам не запустится.

Перед сбросом останови мониторинг и заверши либо отмени активный Prediction
обычными средствами. Сброс не
отменяет Prediction и не делает запросов выплат. После принятого сброса новые
POST-запросы отклоняются. Незавершённая авторизация не мешает сбросу: процесс
закрывается, а её возможные записи удаляются при следующем запуске.

При ошибке удаления маркер сброса сохраняется для повторной попытки, профиль
не загружается частично. Сброс относится к текущему профилю, в том числе
заданному через --data-dir; другие профили не меняются.
